SAMEER JOB AGENT — EASY UPLOAD VERSION

You only upload these 5 files:
1. index.html
2. jobs.json
3. config.json
4. scan.yml
5. README.txt

IMPORTANT:
After uploading, GitHub must place scan.yml inside .github/workflows for Actions to recognize it.
If GitHub's web uploader does not let you choose that folder, use the GitHub web URL below to create the workflow file after uploading the other four files:

https://github.com/sameervj16/sameer-job-agent/new/main/.github/workflows

Set the filename to:
scan.yml

Then paste the contents of scan.yml from this package and commit.

GitHub Pages:
Settings → Pages → Deploy from branch → main → /(root).

The dashboard is browser-only. It does not store LinkedIn/Naukri passwords and does not bypass CAPTCHAs.
